打开 http://127.0.0.1:5173/ 并 Ctrl+F5。使用按钮演示完成 10 次，可以查看战报样式、挤压回弹受击、胜利动作及本地音效；演示结果明确标记，永不调用 AI。真实模式亲自开启摄像头完成 10 次，核对实际计数、计时、击败结果，再点击召唤 AI 战报（每局一次）。不配置 Key 时该按钮会显示本地备用结果，游戏仍可继续。

## 北京地域，只需在本地配置

1. 打开项目根目录 .env.local（已创建、Git 已忽略），只在本地把 Key 填到 DASHSCOPE_API_KEY= 后面。不要发给聊天，不要使用 VITE_ 前缀。仓库里的 .env.example 始终留空。
2. BAILIAN_BASE_URL 使用你百炼控制台显示的北京 OpenAI 兼容 base URL，末尾为 /compatible-mode/v1，不含 /chat/completions。当前示例为 https://dashscope.aliyuncs.com/compatible-mode/v1；如果你的业务空间提供 https://业务空间ID.cn-beijing.maas.aliyuncs.com/compatible-mode/v1，使用控制台对应地址，勿自己猜业务空间 ID。BAILIAN_MODEL 默认 qwen-flash；需在你的账户中有调用权限。
3. 保存后让 Codex 重新启动本地 Vite 以读取环境变量。完成新一局真实挑战再点击 AI 按钮；若本局此前已请求过，按钮不重试，避免重复消耗。

没有必要安装模型 SDK 或单独运行后台命令。npm run dev 由 Vite 的服务器中间件提供同源 POST /api/review；前端只发送本局 ID、次数、整数秒和模式。Key 只由 server/review.mjs 读取，既不写入前端代码也不进入 Vite 构建。api/review.mjs 仅为未来经批准部署时的服务端入口，本轮没有部署。

## 调用与成本控制

默认先显示本地趣味称号与文案，真实局用户主动点击才调用 AI；没有自动调用、轮询或自动重试。按钮有同步重复点击保护；服务器对同一个 roundId 缓存正在进行的 Promise 与结果，包括失败备用结果，同局不同数据拒绝。每进程最多缓存 512 局，满且无法清理过期项时只返回本地评价。

每次请求 max_tokens=280、enable_thinking=false、单次上游超时 8 秒，前端超时 10 秒。每进程每分钟最多 5 次，上游每日默认最多 20 次（UTC 日）；BAILIAN_DAILY_LIMIT 可以调小，最大 100。额度按尝试扣减，失败不自动补调。

这些是本地 / 单进程的内存保护，重启会重置，多实例也不共享计数；不是付费硬上限或公开网站的完整防滥用方案。公开部署前需另行批准并配置百炼侧额度 / 预算及部署访问控制。是否消耗免费额度、实际费用由账户权益和供应商计费决定，本项目没有承诺免费调用。本轮没有开通或购买付费服务。

## 可信数据与内容边界

结算的次数、秒数、击败结果在第 10 次事件到达时固定，AI 不能修改。AI 仅返回游戏称号和趣味故事；本地称号依据完成与用时区间选择，称号没有排行榜或健康意义。不生成卡路里、健康收益、标准姿势评价等无法核验指标。固定提示词、受限 JSON 输出、长度和敏感指标文案检查，异常都回退；关键词检查不是对所有可能幻觉的形式化保证。

AI 只接收本局次数、用时和固定故事背景；摄像头原视频与人体关键点始终不上传、不录制。没有账号、数据库、Agent 或云端语音。

## 声音和动画

受击：CSS 挤压 / 回弹、场景短震动、原有伤痕和血条；音效是本地双层短音。通关：保留彩屑，增加怪兽认输动作和四音胜利旋律。系统设置减少动态效果时关闭新增动画。

识别状态优先使用本地短提示音；只有 Web Audio 不可用而本地语音可用时才回退本地语音，不调用云端 TTS。识别声音由摄像头区声音提示开关控制，攻击 / 胜利音由战斗音效开关控制；全部静音时将这两个开关关闭。
