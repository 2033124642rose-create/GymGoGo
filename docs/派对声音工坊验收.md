# 派对声音工坊 · 待真人试听定稿

2026-10-30。本轮仅本地语音体验优化，不接付费TTS，不调用百炼或修改出题/判题逻辑，不上传/部署/创建最终提交。

## 原实现与音质限制

原QuizSpeech使用设备本地SpeechSynthesis，选第一个本地中文语音；Bingo同样交给中文语音朗读，rate1.15/pitch1.3，怪兽rate1.05/pitch1，整句播读。不是未设置voice而直接默认，但固定取第一个中文声音，也没有英文优先、候选比较或录音。LocalCuePlayer原识别/准备提示也是本地中文选择。

本轮实际浏览器（内置Chromium）列出Microsoft Huihui、Kangkang、Yaoyao三种本地中文，没有本地英文。其他浏览器/设备列表可能不同，运行时枚举并监听voiceschanged，不把本机列表硬编码进产品。没有自然度评分：语速/音调与停顿只能改变呈现，不能将旧系统TTS变成真人表演。未将任何候选定稿；试播后的临时选择已恢复自动选项。

## 本轮交付

- 创建本地派对页面、战斗页增加声音工坊入口，不需开启AI或摄像头即可试听。游戏中打开会先休息并暂停推理/动作语音，关闭后手动继续；不跨玩家计数。
- 三个独立角色配置：成功（初始rate1.02/pitch1.12）、主持（.98/1）、怪兽（.94/.88）。用户可选本地voiceURI、调速调音；存当前浏览器localStorage，设备没有原voice时回退并显示实际名字。自动成功声优先本地英文，再本地中文；主持/怪兽优先本地中文。在线声音可查看但不选择、不发送文本。
- 预览Bingo、下一位勇者及固定中文吐槽样例不请求模型；怪兽实战仍使用本次AI返回的原monsterReaction，不替换文本、不新增API。按标点或最多36字符切段、段间150ms停顿；分段拼接等于原文。
- Bingo可导入本地音频，使用blob URL优先播放，失败/6秒未结束时回退本地TTS。限2MB，建议1–3秒，不读取麦克风、不上传，不把测试音频冒充真人录制素材。当前仓库没有真人录音，刷新后需重新导入；关闭页面/替换音频释放对象URL。
- 复用BattleAudio增加轻量两音成功声、下降失败声；仍受原战斗音效开关控制。识别/准备短提示沿用LocalCuePlayer，派对只传角色参数与短文案；单人默认参数和文字不变。
- 语音启动2.5秒超时、每段8秒上限、整段15秒兜底；失败保留文字并继续，切声/停止/退出/换人取消旧播放和定时器。Bingo完成的自动交接、结果去重、答题待机与AR/计数机制保留。

测试中确认本地Windows原子文件替换偶发EPERM，而非语义判题失败。仅对持久文件替换的EPERM/EACCES/EBUSY增加最多3次15ms等待；不重新发送模型请求、不重复预留额度，持续失败仍关闭调用。模拟测试验证一次请求/一次扣额；未改AI提示词或判题规则。

## 真实浏览器与自动测试边界

浏览器实际枚举三声音，分别启动Yaoyao的Bingo、Huihui主持提示、Kangkang分段吐槽，并测试切换/停止；以浏览器播放回调确认启动/结束，不声称人工听感已通过。未请求摄像头/麦克风或模型。最终声音由项目所有者亲自试听决定。

自动测试覆盖本地/在线过滤、英文优先与无合适语音、分段文字保持、角色参数、录音失败回退、取消/超时、结果一次播放与切换、声音工坊交互，以及原待机/语音/AR/计数/派对回归。具体通过数量见测试记录。

## 你如何试听（不消耗AI额度）

1. 刷新 http://127.0.0.1:5173/ ，点创建本地派对，再点声音工坊·选声音与试听。不用勾AI或开启摄像头。
2. 欢快活泼型依次试听Huihui/Yaoyao/Kangkang的Bingo；本机无英文可选，不把中文读法当作自然英文配音已解决。
3. 自然主持型选择中文声音试听下一位勇者，调语速；调皮搞怪型试听中文分段吐槽，调音调。切另一声音前可停止当前试听。
4. 有自己的Bingo录音时，用本地文件选择器导入再试听欢快型；这是本地读取，不是上传到服务器。没有录音可先保持TTS。
5. 关闭工坊后，你的角色选择会用于派对实战。请告诉我喜欢的三个声音与参数；没有合适声音也请直说。需要验证真实AI结果时仍使用原已批准额度，本轮不扩额。

当前未解决的质量边界：三种现有本地TTS仍可能机械；没有英语声音或真人Bingo素材，不承诺真人感。实际听感、音量和角色匹配等待用户试听，不自行定稿。
