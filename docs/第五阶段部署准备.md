## 部署方案

React + Vite 静态产物 dist，加根目录 api/review.mjs 的 Node Vercel Function。vercel.json 指定 Vite、npm run build、dist、函数最长 15 秒与摄像头同源权限策略。没有 SPA 多页面路由，无需将 /api 或静态模型重写到 index.html。

本地 npm run dev 仍由 Vite 中间件使用 server/review.mjs，公网函数直接导入同一模块，不依赖本机进程或代理。生产函数以 publicMode=true 固定关闭模型生成，返回明确的公网 AI 暂未开放提示；不要在 Vercel 填百炼 Key。本地忽略的 .env.local 继续用于用户本人体验，绝不能使用 VITE_ 前缀。

Vercel 导入配置：Framework Vite，Build npm run build，Output dist，Node 22.x，保留 npm lockfile。使用 Hobby 个人非商业展示，不购买升级、数据库、限流服务或额外域名。免费计划有使用额度，不能承诺无限访问；超额行为以账户计划规则为准。

## 公开 AI 成本方案

第一版公网 AI 关闭，因此不会产生百炼模型调用费用。现有输入校验、2KB 请求限制、280 输出 token、超时、去重保留，但进程内每分钟 / 每日计数不是可靠全局控制，不能据此开放公开 AI。

未来如需开放：需用户另行批准，使用支持原子扣减的持久配额存储，为调用预先占用全局每日预算；幂等 roundId、并发控制、每访客限额、供应商端可执行的硬额度或独立低额度凭证，并核验服务条款和费用。无法获得硬边界时继续禁用公网 AI。没有擅自创建任何此类服务。
