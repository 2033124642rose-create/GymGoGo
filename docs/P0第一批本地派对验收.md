# P0 第一批 · 第一关本地派对说明与真人验收

日期：2026-10-29。状态：项目所有者已明确确认真人验收通过、没有未解决问题；本地归档，未上传、未部署。当前公网仍为已验收单人版本。本批次只实现史莱姆森林，不开放幽灵/巨龙或团队AI。

## 已实现的本地流程

首页“创建本地派对” → 2–6人昵称输入 → 第一关 → 当前玩家主动准备 → 复用连续识别约2秒/3秒倒计时 → 有效下蹲与起立攻击 → 当前玩家达到2次 → 主动点击下一位 → 全员各2次 → 第一关通关和萌芽伙伴徽章。昵称相同也以玩家编号区分。输入空白或超过12字符会拒绝创建；昵称仅当文本显示，不执行HTML。

Boss最大HP=人数×2×10；每次正式有效动作减10，团队合计与个人次数相加一致。2人共4次/40HP，6人共12次/120HP。次数由复用的SquatCounter输出，不设派对手动加次数按钮；试听攻击音不改变HP或贡献。

## 最终跳过与休息规则

- 跳过：保留当前玩家已完成次数，剩余任务排至本关队尾。
- 达标：当前玩家完成2次后从待完成队列移除，不再次排队。
- 休息：暂停计数、清空未完成动作和就位倒计时，保留所有已完成次数、血量与贡献；继续后回到待准备，不自动开练。
- 所有未完成玩家均在本轮选择跳过：进入“本关已暂停”，只可主动继续、休息或退出，不无限轮转、不赠送伤害。继续后开启新一轮跳过记录。
- 换人/暂停恢复：废弃旧尝试标识与半次动作，每次重新准备并建立新基线。正式挑战之外的动作不计数。
- 退出：先暂停并要求确认；确认后停止摄像头，显示真实贡献与未通关摘要，不发奖励。大屏会恢复普通页面。取消退出留在休息状态，不暗中继续计数。

MediaPipe/CameraController、SquatCounter、ReadyGate、trainingFeedback、BattleAudio、旧战报服务端与部署配置均未改算法或契约。切换模式时仅一套摄像头界面挂载；不启动两个采集。语音采用已验收的测试/开关/稳定提示逻辑，不做昵称配音。怪物伤痕按受击比例映射为有限卡通标记，真实攻击次数独立展示，不冒称生成额外真实动作。

计数尝试创建目标=个人本关剩余次数。PartySession只接受当前正式active阶段、当前attempt标识、严格递增repIndex的事件。一次尝试结束或换人就使旧标识失效；计数器重新创建，不将前一玩家的底部状态/参考姿态带给下一位。后台/中断仍通过原就位与计数中断机制处理。

昵称、进度只在当前内存，刷新会丢失；无账号或身份识别，由现场确保当前玩家一人入镜。整场经过时间含轮换和休息，不按速度排名。贡献百分比四舍五入，只根据已完成次数；不表示标准姿势或健康收益。本批次不发出团队战报请求，原单人AI/备用能力保留，公网AI保护未更改。

## 请用户亲自验收

先用2名玩家；可以由同一人扮演两个测试昵称，但不同真人的身高/站位适应仍需另行验证，不能将其算作已测。

1. 打开本地地址，点“创建本地派对”，选择2人并填昵称。应看到第一位、0/2、40HP；创建本身不应申请摄像头。点击测试语音，再亲自开启并授权摄像头，可进入战斗大屏。
2. 点击准备挑战后走远入镜。倒计时期间不加数；第一位完成2次后应停在2/2、20HP；再做动作不继续扣血。点击下一位、准备，第二位重新入镜并完成2次，才显示第一关通关、0HP及徽章。下方贡献应为各2次、各50%。
3. 新建一场测试跳过/休息：第一位完成1次时休息，期间动作不加数；继续需重新准备。随后跳过，下一位再跳过，必须显示本关已暂停及继续/休息/退出三个选项；HP仍为30。继续后保留第一位1次，只需补1次，不应重新要求完整2次。
4. 测试计数隔离：当前玩家下蹲未起立就跳过，下一人入镜站直，不能凭空加数；准备后完成新下蹲起立才算。确认退出本关后应停止摄像头、显示未通关和实际贡献。最后返回单人模式，确认原10次/演示及语音入口仍正常。

先反馈通过项与异常现象，不需要发录像、朋友姓名或设备隐私。2人真人通过前不宣称6人真人已验收。验收前不创建本批最终提交，不进入P0第二批。
