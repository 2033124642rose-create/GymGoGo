# 产品需求 v0.3

记录日期：2026-10-27。来源：项目所有者提供的初始需求。

## 目标与场景

面向希望通过游戏获得健身动力的用户：在电脑浏览器打开摄像头，通过完成深蹲击败怪兽，查看本局训练数据和趣味评价。

项目希望在 7 天内产出可演示的 MVP，形成完整的开源开发记录。预算尽量为零。

## 核心流程

进入首页 → 阅读本地摄像头分析说明 → 主动授权摄像头 → 调整站位 → 开始训练 → 有效深蹲触发攻击 → 达到目标后通关 → 查看次数、时长及评价 → 重新挑战。

## 功能与验收标准

| 功能 | 验收标准（待实现后验证） |
| --- | --- |
| 响应式游戏页面 | 电脑可完整操作；窄屏下内容可读，主要按钮可用 |
| 姿态识别 | 授权后能显示摄像头画面及人体关键点 |
| 深蹲计数 | 一次完整的下蹲和起立只加一次；站立及不完整动作不应计数 |
| 游戏联动 | 有效计数对应一次攻击；血量不低于零；达标只结算一次 |
| 训练结算 | 次数、时长、关卡结果与本局实际状态一致 |
| 异常处理 | 拒绝授权、无摄像头、模型加载失败和人体丢失时显示明确提示 |
| 趣味评价 | 默认模板可用；可选 AI 调用失败后回退模板，不影响结算 |
| 隐私和密钥 | 原始视频不上传；密钥仅在服务端环境变量中读取 |

第一版不包含复杂账号、付费、自训练模型、医学及精准姿势诊断。AI 评价仅用于娱乐鼓励。

## 待实现时确定

- 每关目标次数、血量与伤害映射。
- 深蹲角度阈值、持续时间、可见度阈值及校准方案。
- 百炼模型选择、调用限制、超时和部署端环境变量配置。

这些参数尚未通过真实动作测试，不作为已验证能力宣传。

## 2026-10-28 · UX-001：远距离识别反馈不可读

以下保留第一轮训练大屏方案的决策记录；当前交付以文末“沉浸式游戏战斗模式”修订为准。

**来源**：第二阶段项目所有者的真人测试。用户需要远离电脑才能全身入镜，但右侧预览和文字随距离变得难以看清，无法及时确认是否识别成功。这是实际测试发现的体验问题，尚无距离、人数或改善比例等量化数据。

**解决方案**：在营地观测区增加“训练大屏”。优先以页面内沉浸界面占满应用视口，无需申请系统全屏权限；用户可额外点击“系统全屏”。继续使用原视频、骨骼画布和识别会话，不重开摄像头、不改变 MediaPipe 算法或隐私策略。

| 需求 | 验收标准 |
| --- | --- |
| 大屏入口与退出 | 摄像头区域有明显入口；可用退出按钮或 Esc 返回原页面，退出本身不关闭摄像头 |
| 视频与骨骼 | 尽可能利用视口，以 contain 原比例显示完整画面，不裁掉头、脚等区域；骨骼和视频对齐 |
| 远距离状态 | 视频外侧用大字号、高对比文字显示识别成功、等待全身入镜、请让全身入镜或未检测到人体，不只靠颜色区分 |
| 声音反馈 | 大屏内可开关和试听；有本地中文语音时播报，否则使用本地提示音。稳定 1.2 秒后才提示，提示之间至少 4.5 秒，不逐帧重复 |
| 浏览器限制 | 系统全屏被拒绝或不存在时继续页面大屏；声音被阻止时提示点击试听或依靠大字，不影响识别 |
| 会话与隐私 | 进出大屏不重新授权；关闭摄像头仍停止采集与识别；不上传视频、不保存录像，不调用云端语音服务 |
| 阶段边界 | 保留原首页、模拟游戏与森林风格；不实现自动深蹲计数、真实攻击联动或 AI API |

当前状态：已实现并通过自动测试 / 非摄像头浏览器界面验证；等待用户真人测试远距离看清、听清、骨骼对齐及关闭效果。验收前不创建最终 Git 提交，不进入第三阶段。

## 2026-10-28 · 大屏修订：沉浸式游戏战斗模式

**变更来源**：用户重新评估，摄像头独占大屏会遮蔽怪兽，损害健身游戏的核心趣味。在 UX-001 远距离可读性目标上修订方案，不将此设计决策虚构为新的用户数量或效果指标。

| 需求 | 当前验收标准 |
| --- | --- |
| 同屏战斗 | 点击“战斗大屏”，怪兽区、血量与摄像头骨骼同时可见；电脑屏幕左右约 55:45 |
| 游戏连续性 | 保留怪兽呼吸、受击、伤痕和通关反馈，进出不重置本局游戏或摄像头 |
| 远距离信息 | 底部巨大模拟计数（例如 3 / 10）与高对比识别状态，成功显示“识别成功”，不完整时提示“请调整站位” |
| 真实 / 模拟边界 | 模拟计数与攻击来自既有手动按钮；真实姿态结果不会增加次数或扣血，页面与计数区均明确标注 |
| 显示与推理解耦 | 显示框按视频比例 contain，不裁人体；推理沿用原采集条件与基于 videoWidth/videoHeight 的宽度上限 640px，不依赖 CSS 或 clientWidth |
| 声音与退出 | 延续稳定变化才提示的本地中文语音 / 提示音、静音、试听、Esc 与退出；可选系统全屏覆盖整个战斗区而非仅摄像头 |
| 自适应与隐私 | 适配普通电脑尺寸，保持森林风格；视频不上传、不录制，算法和隐私策略不变 |

实现、49 项自动测试及未开启真实摄像头的浏览器布局复测已完成。远距离真人骨骼跟随、提示听辨、进出不中断仍待用户验收；第二阶段未最终提交，第三阶段未开始。
