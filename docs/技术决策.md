## 2026-10-27 · 第一阶段首页交互原型

- 正式产品名称统一为 **GymGoGo**；目录保持 `D:\gymgogogo`。
- 实际安装：React / React DOM `19.3.1`、TypeScript `5.9.3`、Vite `7.3.7`、React 插件 `5.2.0`、Lucide React `0.468.0`；精确依赖树保存于锁文件。使用当前 Node.js `22.14.0` 完成构建。
- 暂定视觉方向：深紫冒险竞技场、薄荷绿怪兽、荧光绿行动按钮。该方案是供验收的初稿，尚未确认最终风格。
- 怪兽使用内联 SVG，场景和动效使用 CSS，图标使用 Lucide；无外部图片和字体请求，无额外素材 API 成本。
- 使用 React 状态 `idle / active / won` 管理演示；目标 10 次、每次伤害 10，怪兽生命值由计数派生，避免两个状态不一致。计时依据时间差计算，通关停止，重新挑战归零。
- 第一阶段仅允许按钮模拟动作，不安装 MediaPipe、不调用摄像头或 AI；所有相关区域标注演示或未接入，后续不把模拟交互当成识别算法。
- 保持前端单项目，不提前建立后端和账号系统。开发服务绑定 `127.0.0.1:5173` 并启用严格端口，方便本机验收。
- npm 缓存放在项目的 `.npm-cache/` 并忽略，避免默认缓存目录写权限问题；不修改全局 npm 配置。

## 2026-10-28 · 留白与受击反馈调整

- 采用更宽的 1800px 内容容器与更小的桌面内边距，在桌面增加有效空间，继续保留页面两侧留白和原有移动端断点。
- 复用现有 SVG 怪兽，预定义 10 处不同位置的卡通伤痕，按当前计数显示前 N 处；表情和台词随受击阶段变化。伤痕与 HP 都由同一计数派生，重置自动恢复，不新增独立伤痕状态或外部生成服务。
- 本次只调整第一阶段原型，不改变按钮模拟与未接入真实识别的边界。

## 2026-10-28 · 文字与轻量趣味反馈

- 冒险指南使用响应式卡片布局，标题 18px、正文 14px，空间不足时分行或改单列，不依靠缩小正文适配。
- 新增 `src/playful.css` 集中管理本轮字号和趣味样式，沿用现有页面结构与配色。仅使用本地 CSS、SVG 和图标，不新增依赖或外部服务。
- 累计命中提示从现有 count 派生，不增加限时连击规则；庆祝粒子仅在通关时播放一次，不计为新训练功能。
- 动画以 transform / opacity 为主；系统选择减少动态效果时，隐藏粒子和火花、关闭动画与过渡，保留数字、文字和血量反馈。

## 2026-10-28 · 森林叙事与视觉语义

- 主标题负责产品叙事，使用居中大字；关卡标题为左对齐的次级信息，怪兽为场景角色。窄屏主标题分两行，保留大小层级。
- 从紫色通用游戏面板转为统一森林配色。通过 CSS 变量区分血量 `--leaf-health`（柔和浅绿）、行动 `--leaf-action`（#a5ef3f）和标记 `--leaf-note`（#d8e6aa）；血条渐变围绕浅绿层级设置，不与主按钮同色。
- 采用本地原创 SVG 森林插画，以共享透视和地面连接角色与背景，替换独立装饰贴纸。只保留三处微光，减少持续动效密度；原有受击和通关反馈保留。
- 用细微不对称圆角、内高光、低对比边缘和局部点状纹理统一按钮、血条、图标底座与卡片，不引入 UI 库或素材服务。
- 世界观文案不替代功能状态：营地观测区仍明确说明演示、摄像头与识别未接入。
