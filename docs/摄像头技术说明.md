## 功能边界

营地观测区只显示摄像头画面、人体骨骼和主要关节的可见性。它不计算深蹲、不判断姿势正确性，不触发攻击，也不提供医学建议。下方按钮模拟挑战独立运行，计数与用时仅属于模拟游戏。没有账号、后端、录像或大模型 API。

## 实际数据流

点击开启 → 浏览器权限 → 本地 MediaStream → video 镜像显示 → 低分辨率 ImageBitmap → 本地 Worker → MediaPipe Pose Landmarker → 关键点 → canvas 叠加。

ImageBitmap 只从页面线程传到同一浏览器的后台线程，不是上传。程序没有上传视频、录制、截图存储或发送关键点的接口。关闭、取消、页面离开、设备中断和识别出错时，停止所有本会话媒体轨道、清空 video.srcObject、取消下一帧、清空 canvas、终止 Worker。迟到的授权会立即停止其媒体轨道，不能重新开启已关闭会话。

浏览器仍可保留“网站已获摄像头权限”的设置，它与正在采集不同。用户验收应查看摄像头活动指示 / 设备灯是否停止，不要求撤销已授予的网站权限。

## 实现取舍

- 使用 classic Worker 加载 MediaPipe IIFE，因为其 WASM 加载器使用 importScripts；避免把同步推理放在 React 主线程。
- 模型以 VIDEO 模式、单人、无分割掩码运行；检测 / 存在 / 跟踪阈值均为 0.5。
- 捕获宽度最多 640px，不放大低分辨率输入。推理目标上限 15 次/秒，慢设备按上次推理耗时降低频率；一次仅允许一帧在途，不积压帧。
- 视频和骨骼同时镜像，显示比例跟随实际视频分辨率；整幅显示而非裁剪。canvas 尺寸仅在输入分辨率变化时设置，避免每帧清空引起闪烁。
- 核心可见性检查为双肩 11/12、双髋 23/24、双膝 25/26、双踝 27/28；visibility 至少 0.5 且位于画面内部。绘制可见的鼻点、身体与四肢，省略脸部细节，避免画面杂乱。
- 连续 3 次相同识别状态后才更新状态文字，减少闪动；每次结果立即清理并重绘骨骼，不保留丢失人体的旧线条。
- “人体超出画面或关节点不清晰”并不是精确出框检测，也可能来自遮挡、低光或模型误差。初次无人显示等待；曾出现人体后无人显示人体超出画面。
- 视频播放等待上限 15 秒、模型加载 45 秒、单帧响应 10 秒。失败时释放摄像头并给出重试提示。
- 仅支持提供 getUserMedia / Worker / OffscreenCanvas / createImageBitmap 的安全环境；建议本机新版 Chrome / Edge，通过 localhost 或 HTTPS 访问。

## 已验证与限制

初版第二阶段 21 项 Vitest 测试通过；加入 UX-001 大屏后为 44 项，修订为战斗大屏后累计 49 项通过。类型检查、生产构建和静态资源 HTTP 检查通过。真实浏览器中 Worker 加载 GPU 模型成功，程序生成的空白帧返回空关键点；一次暖机后空白帧推理约 41.4ms。冷启动帧在本次环境耗时约 1.3–4.3 秒，这些不是摄像头真人帧率测试，也不承诺设备实时性能。

权限异常使用模拟媒体设备测试，未操作用户真实权限；真人关键点跟随、出入画、实际关闭设备灯、实际 GPU→CPU 回退和多浏览器兼容性仍待实机验收。没有保存任何用户摄像头画面作为证据。

## 你亲自测试（每项通过或失败均可反馈）

1. 打开 `http://127.0.0.1:5173/`。刚打开时应显示摄像头已关闭，不应主动请求权限。
2. 点击右侧“开启摄像头”，亲自允许浏览器授权。首次模型和着色器准备可能需要数秒；应先看到画面，再看到识别状态。
3. 单人全身入镜，确认肩膀、髋部、膝盖和脚踝能被标记，活动手臂和腿时骨骼跟随；不要将其作为精确姿势诊断。
4. 离开画面，再返回；或只让上半身入镜，观察等待 / 人体超出画面 / 关节点不清晰 / 识别成功等状态。全身关键点清晰可见时应显示识别成功。
5. 点击“关闭摄像头”，确认画面清空、设备灯或浏览器采集标记熄灭。再次开启验证可恢复。
6. 在摄像头开启时运行按钮模拟挑战，确认只有按钮增加次数，真实动作不会自动扣血。可另行尝试拒绝授权，再从地址栏恢复权限重试。

如失败，请反馈浏览器名称、页面原文提示、失败发生在授权 / 模型加载 / 入镜 / 关闭哪个环节。不需要发送露脸截图或原始视频。

## 沉浸式游戏战斗模式复验（当前方案）

该功能来源于真人测试的远距离可读性问题，以及用户希望保留怪兽趣味的设计修订。当前战斗大屏替代摄像头独占大屏，仍属于第二阶段。没有修改 MediaPipe 检测、关键点可见性阈值、摄像头采集或视频本地处理策略。

1. 先在普通页面亲自开启摄像头，再点营地观测区的“战斗大屏”。左侧应显示怪兽和血条，右侧显示同一真实视频和骨骼，不重复授权或重开会话。
2. 在底部点击“开始挑战”，手动模拟 3 次，检查巨大 3 / 10、怪兽 70 HP 和伤痕；这是按钮演示，实际做动作不会自动增加次数。可点“试听提示”确认声音，试听不是识别结果。
3. 向后站到全身入镜，确认怪兽与摄像头同时可见、底部“识别成功”和模拟次数容易看清；持续保持成功不应重复轰炸提示。稳定变化后约 1.2 秒才开始提示，前后提示间隔至少 4.5 秒。
4. 离开画面或只露上半身，再返回；检查“未检测到人体” / “请调整站位”与成功提示。应显示完整视频、头脚不被显示区域裁掉，骨骼对齐。
5. 有本地中文声线时朗读状态，没有时提示音上扬双音代表成功、下行双音提醒入镜。浏览器阻止声音会显示说明，请再点试听；无声音设备时仍可用大字判断。不使用远程语音服务。
6. 页面大屏已经占满应用视口，不需要系统全屏权限。想隐藏浏览器边栏可选点“系统全屏”；如果拒绝或不支持，仍保留页面大屏。按 Esc 或点“退出大屏”恢复普通页面，摄像头继续采集。
7. 在大屏内或退出后点击“关闭摄像头”，检查设备灯 / 活动标记停止。退出大屏与关闭摄像头是两个不同操作。

显示与推理是两条独立链路：预览框大小只由布局和视频比例决定；识别仍读取内在视频分辨率，例如 1280 × 720 输入缩到 640 × 360，而不是读取预览 CSS 尺寸。新增测试已覆盖小框与大屏切换时此输入保持不变。
