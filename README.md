## MVP 范围

- 摄像头本地分析人体关键点，使用 MediaPipe Pose Landmarker 和状态机计算有效深蹲。
- 每次有效深蹲触发攻击，显示怪兽生命值、训练计数、计时和通关结算。
- 处理摄像头拒绝授权、人体识别失败和误计数场景。
- AI 趣味评价优先采用本地模板；可选百炼接口通过服务端调用，密钥不进入浏览器或仓库。
- 不开发复杂账号、付费功能或自有模型，不提供医学及精准姿势诊断。
- 原始摄像头画面默认仅在浏览器本地处理，不上传、不录制。

## 本地运行

环境：Windows / PowerShell，已在 Node.js `v22.14.0`、npm `10.9.2` 下验证。

```powershell
cd D:\gymgogogo
npm ci --cache .npm-cache
npm run dev
```

浏览器打开：<http://127.0.0.1:5173/>。已安装依赖时只需执行 `npm run dev`。开发服务器仅监听本机；端口被占用时会报错，不自动切换地址。终端按 `Ctrl+C` 可停止服务。

```powershell
npm run typecheck
npm test
npm run build
npm run preview
```

`build` 包含 TypeScript 检查并生成 `dist/`；`preview` 的地址以终端输出为准。项目内 `.npm-cache/` 已忽略，用于避免 Windows 默认缓存目录的权限问题。`package-lock.json` 固定依赖解析结果。

首次安装后会自动准备 MediaPipe 本地资源，启动与构建前也会检查复制。模型随项目保留，WASM 从 npm 依赖生成并被 Git 忽略；浏览器运行时无需访问第三方模型 CDN，不需要任何 API Key。

## 当前结构

- `src/App.tsx`：首页组件、SVG 怪兽和模拟挑战交互。
- `src/camera/`：独立摄像头区域、权限与资源生命周期、关键点绘制。
- `public/pose-worker.js`：本地 MediaPipe 后台识别。
- `public/models/`：官方轻量预训练模型，不是项目自行训练的模型。
- `src/style.css`：游戏视觉、响应式布局、动画及减少动态效果适配。
- `public/favicon.svg`：产品图标；插画由项目内 SVG/CSS 实现，不依赖远程图片或字体。
- `docs/evidence/`：真实桌面与窄屏截图。

摄像头仅在点击开启后使用；不上传、录制或保存原始视频。本项目没有账号或后端。后续功能是否完成以开发日志与测试记录为准。
