# GymGoGo · 不用手柄，靠深蹲打怪！

一台电脑、一个摄像头，2–6 位朋友轮流用深蹲攻击怪兽，戴上跟随头部的 AR 帽子，一起完成三关冒险。启用服务后，还能迎接 AI 怪兽的健身知识挑战：用自己的话回答，AI 理解含义并判题。

**版本说明（2026-10-30）：本地版本已包含派对、AR 帽子与 AI 问答；[当前公网网站](https://gymgogo.pages.dev/)仍是已验收的单人版本，公网 AI 关闭。本次产品包装仅在本地完成，云端接口与全局预算现已完成本地模拟验证，独立私有 Worker 与 SQLite DO 已部署，模型 Secret 及生产/预览服务绑定已配置；AI 双开关仍关闭、金额预算为零。当前准备发布关闭 AI 的预览版，尚未完成真实模型公网验收，不合并生产。** 不要把本地功能视为已部署功能。

## 怎么玩

1. 点击「立即开始」，创建 2–6 人派对，填写昵称、选择皇冠 / 海盗帽 / 魔法帽 / 派对帽。无需真实姓名。
2. 开启摄像头并授权，点击「准备挑战」后走远，让主要关节完整入镜，等待就位与倒计时。
3. 当前玩家完成明显下蹲 → 起立，每个有效动作攻击 10 点。支持战斗大屏、声音开关、轮换、跳过及休息。
4. 选择 AI 知识挑战时，达到个人目标后姿态推理待机。走近电脑输入答案，没有答题倒计时；每人每关一次问答。
5. 答对 Bingo 并继续；明确答错才触发怪兽占领和本关失败。无法判断或接口异常不会判失败，可按提示手动重试或退出。
6. AI 模式全员完成动作且答对才解锁下一关；纯运动模式无需答题。最后查看实际有效次数、团队贡献与徽章。

| 关卡 | 每人有效动作 | 初始 Boss 血量 | 通关奖励 |
| --- | --- | --- | --- |
| 史莱姆森林 | 2 次 | 人数 × 20 | 萌芽伙伴徽章 |
| 幽灵秘境 | 3 次 | 人数 × 30 | 驱雾小队徽章 |
| 巨龙城堡 | 4 次 | 人数 × 40 | 屠龙同盟徽章 |

适合朋友聚会、大学宿舍、家庭互动与轻量团建。同房间、同设备轮流玩，不是线上联机；不拼速度，可休息。原单人 10 次挑战及明确标注的按钮演示保留。暂不提供团队 AI 战报、排行榜或分享卡片。

## 本地运行

需要 Node.js 22 或兼容环境。推荐带摄像头的电脑与 Chrome / Edge。

```powershell
npm ci
npm run dev
```

打开 [本地网站](http://127.0.0.1:5173/)。只在主动点击后申请摄像头权限。停止服务按 Ctrl+C。安装与构建自动准备 MediaPipe WASM；模型使用本地静态资源，不依赖运行时模型 CDN。

```powershell
npm run typecheck
npm test -- --maxWorkers=1
npm run build
npm run preview
```

`build` 包含项目 TypeScript 构建检查。`preview` 只预览生产静态产物，**不提供 Vite 开发问答 API**。开发排查面板仅在本地开发地址增加 `?debug=1` 时显示，生产构建不显示。

## AI 服务与成本边界

本地问答继续使用百炼 `qwen-flash`；服务端统一通过 `AI_PROVIDER`、`AI_BASE_URL`、`AI_API_KEY`、`AI_MODEL` 配置，兼容原百炼变量。[配置与切换说明](docs/AI服务配置说明.md)。出题、判题各一次模型请求；手动重试另计，不自动追加调用。Key 只从服务端环境变量读取，不可写入 `VITE_` 变量、浏览器或 Git。

参考 `.env.example` 在本机配置 `.env.local`，不要发送或提交真实 Key。`GYMGO_QUIZ_ENABLED` 控制本地问答，`QUIZ_MAX_LEVEL` 控制关卡范围；同时必须具有明确授权的次数、金额上限与有效价格配置。已有 `.local/` 预算账本不得删除或清零以绕过限额。修改服务端环境后重启 Vite。详细设置见[本地问答说明](docs/AI知识挑战本地服务与验收.md)。

云端实现采用 Pages Functions → 私有 Worker 服务绑定 → 单一 SQLite Durable Object，所有生产与预览请求共用同一权威账本。默认累计 1000 次、全站每日 300 次、来源每日 60 次及每分钟 10 次，模型调用前事务预留，失败不退回。公网开关默认关闭、费用预算为零；必须先确认百炼免费额度用完即停、配置 Secret / 绑定 / 价格和金额上限，再经授权部署验证。原开发服务仍使用本地文件预算，不等于云端全局额度。详见[云端部署与预算](docs/Cloudflare公网AI部署与预算.md)及[以后更新发布步骤](docs/以后如何更新并发布GymGoGo.md)。

浏览器语音受设备本地语音包与播放权限限制，保留已确定的「调皮搞怪型」方案；可使用语音试听与声音工坊，无需麦克风或付费 TTS。

## 隐私与活动安全

摄像头视频及人体姿态在浏览器本地处理，应用不上传或录制原始视频。AI 模式会在当前标签页保留恢复记录，服务端保存匿名题目、判定与预算信息；题目、参考信息和玩家文字答案会发送到百炼，不发送视频或人体关键点。请勿在昵称、答案中提供敏感信息。纯运动进度只在当前页面，刷新会清空。

这是趣味动作游戏，不提供医学诊断、精准姿势考核、卡路里或健康效果测量。保持适当光线和安全活动空间，根据自身情况调整幅度，不适时停止。

## 实现与验证

React + TypeScript + Vite；MediaPipe Pose Landmarker；Canvas 独立关键点和 AR 图层；配置驱动关卡与动作 / 派对 / 问答状态机；服务端百炼调用与本地持久预算。

- `src/product/`：产品介绍、玩法、场景插画、新手指南和 FAQ。
- `src/camera/`、`src/squat/`：摄像头生命周期、推理待机和动作计数。
- `src/party/`、`src/ar/`：三关、轮换、知识挑战、语音、帽子。
- `server/ai/`：服务端配置与统一 JSON 接口，独立 OpenAI-compatible 适配器；切换服务商不改游戏状态机。
- `server/quiz.mjs`、`server/quiz-store.mjs`：本地问答与持久预算；不是现成的公网问答服务。
- `functions/api/quiz/[[route]].js`：Pages 同源问答入口。
- `cloudflare/worker.mjs`、`budget-store.mjs`：私有 Worker 和 SQLite 权威预算。
- `functions/api/review.js`：单人备用战报，无模型调用。
